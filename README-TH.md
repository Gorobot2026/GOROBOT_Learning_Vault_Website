# GO ROBOT Learning Vault — GitHub Pages + Google Sheets Edition

**เว็บไซต์รวบรวมเกมภารกิจหุ่นยนต์ เอกสาร ใบงาน วิดีโอ และสื่อการเรียนรู้**

ออกแบบให้ผู้เรียนและผู้ปกครองเปิดดูผ่านลิงก์เดียว ส่วนครูผู้ดูแลใช้รหัสผ่านเพื่อจัดการเนื้อหาได้จากหน้า Admin Portal โดยไม่ต้องแก้ไขไฟล์หน้าเว็บทุกครั้ง

## ความสามารถ

| ระบบ | รายละเอียด |
|---|---|
| Public Library | หน้าเว็บสไตล์ Dashboard ธีมม่วง รองรับมือถือ/แท็บเล็ต/คอมพิวเตอร์ |
| หมวดหมู่ | เพิ่ม / แก้ไข / ลบ / จัดลำดับ / เลือก 21 ไอคอน / เลือกสี / ใช้ภาพจริงแทนไอคอน |
| เกมและสื่อ | เพิ่มลิงก์เกมหรือเว็บไซต์ ไฟล์ดาวน์โหลด รูปปก แท็ก คำอธิบาย ลำดับ และสถานะแนะนำ |
| ค้นหา | ค้นหาชื่อสื่อ คำอธิบาย แท็ก และกรองตามหมวดหรือประเภท |
| ระบบไฟล์ | อัปโหลดไป Google Drive ผ่านหน้า Admin หรือวาง URL ไฟล์จากที่อื่น |
| ข้อมูล | Google Sheets มีแท็บ `Categories` และ `Resources` |
| การรักษาความปลอดภัย | ผู้ชมไม่ต้องเข้าสู่ระบบ / Admin ต้องกรอกรหัสผ่าน; ไม่มีรหัสผ่านใน GitHub |
| การเผยแพร่ | เว็บสาธารณะเป็น HTML/CSS/JavaScript ล้วน รองรับ GitHub Pages |

## โครงสร้างโปรเจกต์

```text
go-robot-github-pages/
├── index.html                    ← หน้าเว็บที่ทุกคนเปิดดูได้
├── styles.css                    ← ธีมและ Responsive Design
├── app.js                        ← ค้นหา / กรอง / โหลดข้อมูลจาก Sheets
├── config.js                     ← วาง URL Google Apps Script ที่นี่
├── favicon.svg
├── .nojekyll                     ← ใช้กับ GitHub Pages
├── README-TH.md
└── google-apps-script/
    ├── Code.gs                   ← ระบบฐานข้อมูล + ตรวจรหัส + อัปโหลด
    └── Admin.html                ← หน้า Admin แยกที่รันบน Apps Script
```

> **สำคัญ:** GitHub Pages เป็นบริการโฮสต์ไฟล์เว็บไซต์แบบ Static จึงไม่สามารถรัน Google Apps Script หรือเขียนข้อมูล Google Sheets ตรงบน GitHub ได้ ระบบนี้ออกแบบให้ **GitHub Pages เป็นหน้าเว็บสาธารณะ** และ **Google Apps Script เป็นระบบหลังบ้าน** ที่อ่าน/เขียน Google Sheets และอัปโหลด Google Drive แทน

## A. ตั้ง Google Sheets เป็นฐานข้อมูล

1. เปิด [Google Sheets](https://sheets.google.com) และสร้างไฟล์ใหม่ เช่น `GO ROBOT Learning Vault Database`
2. ในไฟล์ชีต คลิก **ส่วนขยาย (Extensions) → Apps Script**
3. เปิดไฟล์ `Code.gs` ใน Apps Script ลบโค้ดเริ่มต้น แล้วคัดลอก **โค้ดทั้งหมด** จาก `google-apps-script/Code.gs` ไปวาง
4. คลิกปุ่ม **+ → HTML** ตั้งชื่อไฟล์ `Admin` (ไม่ต้องเติม `.html` ในช่องชื่อ) แล้วคัดลอกโค้ดจาก `google-apps-script/Admin.html` ไปวาง
5. คลิก **บันทึก (Save)**
6. เลือกฟังก์ชัน **`setupDatabase`** จากแถบด้านบน แล้วกด **Run** หนึ่งครั้ง
7. Google จะขอสิทธิ์เข้าถึง Sheets และ Drive สำหรับบัญชีของครู ให้ตรวจสอบและอนุญาตเมื่อยอมรับสิทธิ์เหล่านั้น
8. กลับไปรีเฟรชหน้า Google Sheet จะเห็นเมนูใหม่ชื่อ **GO ROBOT**
9. คลิก **GO ROBOT → 2. ตั้ง/เปลี่ยนรหัสผ่าน Admin** แล้วตั้งรหัสผ่านอย่างน้อย 10 ตัวอักษร

ระบบจะสร้างแท็บ `Categories` และ `Resources` รวมทั้งโฟลเดอร์ `GO ROBOT Learning Vault Uploads` ใน Google Drive ให้อัตโนมัติ โดย **ไม่ลบรายการเดิม** หากเคยตั้งค่าไว้ก่อนแล้ว

### ข้อมูลตัวอย่าง

หลังรัน `setupDatabase` จะสร้างหมวดหมู่เริ่มต้น 4 หมวด:

- เกมและภารกิจ
- เอกสารและใบงาน
- วิดีโอและสื่อ
- การแข่งขัน

หมวดหมู่เริ่มต้นยังไม่มีเกมหรือเอกสารจริง สามารถเพิ่มผ่านหน้า Admin ได้ทันทีหลัง Deploy

## B. เผยแพร่ Google Apps Script Backend

1. เปิด Apps Script ที่มี `Code.gs` และ `Admin.html`
2. คลิก **Deploy → New deployment**
3. เลือกประเภทเป็น **Web app**
4. ตั้ง **Execute as: Me (บัญชีครูผู้เป็นเจ้าของ)**
5. ตั้ง **Who has access: Anyone** เพื่อให้ผู้ชมทั่วไปโหลดรายการได้ *โดยไม่ต้องลงชื่อเข้า Google*
6. คลิก **Deploy** แล้วคัดลอก **Web app URL** ซึ่งลงท้ายด้วย `/exec`

รูปแบบ URL (ตัวอย่างโครงสร้าง ไม่ใช่ลิงก์จริง):

```text
https://script.google.com/macros/s/XXXXXXXXXXXX/exec
```

> หากบัญชี Google Workspace ของโรงเรียนไม่อนุญาตตัวเลือก `Anyone` หรือห้ามแชร์ไฟล์ Drive สาธารณะ ต้องขอผู้ดูแลระบบเปิดสิทธิ์ที่เหมาะสม หรือใช้บัญชีที่สามารถอนุญาตการเผยแพร่ได้ ภายในขอบเขตนโยบายของโรงเรียน

### เมื่อแก้ไข Code.gs หรือ Admin.html ภายหลัง

ต้องไปที่ **Deploy → Manage deployments → Edit → Version: New version → Deploy** อีกครั้ง มิฉะนั้น URL `/exec` จะยังใช้โค้ดเวอร์ชันเก่า

## C. เชื่อมเว็บไซต์กับ Google Apps Script

เปิดไฟล์ `config.js` แล้วแก้เฉพาะค่า `APPS_SCRIPT_URL`:

```js
window.GOROBOT_CONFIG = {
  APPS_SCRIPT_URL: "https://script.google.com/macros/s/ใส่รหัสdeploymentจริง/exec",
  SITE_NAME: "GO ROBOT Learning Vault"
};
```

**ห้ามใส่รหัสผ่าน Admin, รหัสบัญชี Google, API key ลับ หรือ Session Token ใน `config.js`, ไฟล์ HTML หรือไฟล์ JavaScript ที่จะอัปโหลดขึ้น GitHub** ลิงก์ `/exec` เป็น URL สาธารณะที่ตั้งใจใช้สำหรับอ่านข้อมูล ส่วนการเขียนต้องตรวจรหัสและเซสชันในระบบหลังบ้าน

## D. อัปโหลดขึ้น GitHub Pages ให้ทุกคนเปิดดูได้

1. เข้า [github.com](https://github.com) และสร้าง Repository ใหม่ เช่น `go-robot-learning-vault` โดยเลือก **Public**
2. ใช้ **Add file → Upload files** แล้วอัปโหลดเนื้อหาจากโฟลเดอร์นี้ขึ้น Repo โดยให้ `index.html` อยู่ใน **root** ของ Repository (ไม่ควรมีโฟลเดอร์ชั้นนอกหุ้มอีกชั้น)
3. กด **Commit changes**
4. ไปที่ Repository → **Settings → Pages**
5. ที่ **Build and deployment**, เลือก **Deploy from a branch**
6. เลือก Branch `main` และ Folder `/ (root)` → **Save**
7. รอให้ GitHub Pages Deploy เสร็จ แล้วเปิดลิงก์ที่ GitHub แจ้ง

รูปแบบลิงก์ที่ได้ (เปลี่ยนชื่อผู้ใช้และชื่อ Repo ตามของจริง):

```text
https://USERNAME.github.io/go-robot-learning-vault/
```

ลิงก์นี้เป็นหน้าเว็บสาธารณะ นักเรียนและผู้ปกครองสามารถเปิดได้โดยไม่ต้องมีบัญชี GitHub หรือ ChatGPT

## E. วิธีจัดการข้อมูลในชีวิตประจำวัน

1. เปิดเว็บ GitHub Pages ที่สร้างไว้
2. คลิก **Admin Portal** หรือ **จัดการคลังสื่อ**
3. ระบบเปิดหน้า Admin ของ Google Apps Script ในแท็บใหม่
4. ใส่รหัสผ่านที่ตั้งไว้จาก Google Sheet
5. ในหน้า **หมวดหมู่** เพิ่มหมวดใหม่ ใส่ชื่อ เลือกไอคอน/สี หรืออัปโหลดรูปภาพเอง
6. ในหน้า **เกมและสื่อ** เพิ่มชื่อ คำอธิบาย เลือกหมวด ประเภทลิงก์หรือไฟล์ รูปปก และแท็ก
7. กด **บันทึก** ระบบจะเขียนข้อมูลกลับไปยัง Google Sheets
8. ที่หน้าสาธารณะ กดปุ่ม **↻ อัปเดต** หรือโหลดหน้าเว็บใหม่เพื่อเห็นข้อมูลล่าสุด

สามารถแก้ข้อมูลจาก Google Sheet ด้วยตนเองได้เช่นกัน แต่ควรรักษาชื่อคอลัมน์เดิมทุกตัว

### กรณีเกมเป็นไฟล์ HTML

- ถ้าเกมเผยแพร่อยู่บน GitHub Pages หรือเว็บอื่นแล้ว ให้เลือก **ลิงก์เว็บไซต์/เกม** และนำ URL ของเกมมาวาง
- ถ้าไฟล์เป็น `.html`, `.zip`, `.pdf`, `.ino`, `.glb` หรือชนิดอื่น ให้เลือก **ไฟล์ดาวน์โหลด** เพื่อให้ผู้เรียนกดดาวน์โหลด
- **การอัปโหลดไฟล์ HTML ไป Google Drive ไม่ได้ทำให้เกม HTML กลายเป็นเว็บที่เปิดเล่นได้โดยตรง** ถ้าต้องการให้กดเล่น ให้โฮสต์ตัวเกมบน GitHub Pages แยกในโฟลเดอร์เกม (หรือใช้ URL ที่มีอยู่) แล้ววางลิงก์เกมในคลังสื่อ

## F. โครงสร้างฐานข้อมูล Google Sheets

### Tab `Categories`

| คอลัมน์ | ใช้ทำอะไร |
|---|---|
| `id` | รหัสหมวดหมู่ ห้ามซ้ำ |
| `name` | ชื่อหมวดหมู่ |
| `description` | รายละเอียด |
| `icon` | ชื่อไอคอน |
| `imageUrl` | URL ภาพแทนไอคอน |
| `accent` | ชุดสี: purple, blue, teal, orange, pink, indigo |
| `sortOrder` | ลำดับแสดงผล (เลขน้อยขึ้นก่อน) |
| `createdAt` | วันที่สร้าง |

### Tab `Resources`

| คอลัมน์ | ใช้ทำอะไร |
|---|---|
| `id` | รหัสรายการ |
| `categoryId` | เชื่อมกับหมวดหมู่ |
| `title` | ชื่อสื่อ |
| `description` | รายละเอียด |
| `type` | `link` หรือ `file` |
| `href` | URL เกม/เว็บไซต์ เมื่อ `type=link` |
| `fileUrl` | URL ดาวน์โหลด เมื่อ `type=file` |
| `fileName` | ชื่อไฟล์ |
| `coverUrl` | ภาพปก |
| `tags` | JSON array ของแท็ก ระบบจัดการให้เอง |
| `featured` | 1 = แนะนำ, 0 = ปกติ |
| `sortOrder` | ลำดับแสดงผล |
| `createdAt` | วันที่สร้าง |
| `updatedAt` | วันที่แก้ไข |

## ข้อควรรู้ก่อนใช้งานจริง

- **ข้อมูลในแค็ตตาล็อกเป็นข้อมูลสาธารณะ** ห้ามเก็บข้อมูลส่วนบุคคลเด็กหรือเอกสารลับในรายการที่เผยแพร่
- ระบบ Admin รหัสผ่านเหมาะกับเว็บไซต์คลังสื่อขนาดเล็ก-กลางที่มีผู้ดูแลไม่กี่คน หากต้องการผู้ดูแลหลายบทบาท/ประวัติแก้ไขรายคน ควรพัฒนาการเข้าสู่ระบบแบบบัญชี Google เพิ่มเติม
- อัปโหลดไฟล์ผ่านหน้า Admin ได้สูงสุด **8 MB ต่อไฟล์** และยังขึ้นกับข้อจำกัด Apps Script/Google Drive ในบัญชีที่ใช้ ไฟล์ขนาดใหญ่ให้ใส่ลิงก์ Drive หรือที่จัดเก็บอื่นแทน
- ไฟล์ที่อัปโหลดจะถูกตั้งค่า **Anyone with the link: Viewer** เพื่อให้นักเรียนเปิดได้ หากนโยบายองค์กรไม่อนุญาต การอัปโหลดจะแจ้งข้อผิดพลาด
- เมื่อกดลบรายการ ระบบลบ **แถวข้อมูลในชีต** แต่ไม่ลบไฟล์ต้นฉบับใน Google Drive เพื่อลดความเสี่ยงลบไฟล์ผิด
- การตั้ง/เปลี่ยนรหัสผ่านทำในเมนู **GO ROBOT** ของ Google Sheet เท่านั้น; ไม่มีปุ่มตั้งรหัสผ่านสาธารณะ
- ถ้าสร้างเว็บเรียบร้อยแต่ยังไม่ได้ใส่ Apps Script URL หน้าสาธารณะจะแสดงหมวดหมู่ตัวอย่างและข้อความให้ตั้งค่า ไม่ใช่ข้อมูลจริง

## ตรวจสอบปัญหาพื้นฐาน

| อาการ | วิธีตรวจ |
|---|---|
| เว็บเปิดได้ แต่ไม่มีข้อมูล | ตรวจ `config.js`, ค่า `APPS_SCRIPT_URL`, และรัน `setupDatabase` แล้วหรือยัง |
| ขึ้นโหลด Google Sheets ไม่ได้ | ตรวจ Apps Script Web App สิทธิ์ `Anyone`, URL `/exec`, และตรวจ Deploy เวอร์ชันล่าสุด |
| คลิก Admin Portal แล้วไม่ได้ | ต้องใส่ URL `/exec` ที่ถูกต้อง และมีไฟล์ `Admin.html` ใน Apps Script |
| เข้าระบบไม่ได้ | ตั้งรหัสผ่านผ่านเมนูใน Google Sheet, ตรวจตัวพิมพ์ใหญ่เล็ก; ถ้าลองผิดหลายครั้งรอ 15 นาที |
| เพิ่มไฟล์แล้วนักเรียนเปิดไม่ได้ | ตรวจการแชร์ `Anyone with the link` และนโยบาย Google Workspace |
| เกม HTML โหลดเป็นไฟล์แทนเปิดเล่น | โฮสต์เกมที่ GitHub Pages แยก แล้วใช้ URL แบบ `link` |
| แก้ Code.gs แล้วไม่เปลี่ยน | Deploy Apps Script เป็น **New version** |
